LTE Modem Firmware Update Guide 
 
 
1. Uncompressing the LTE modem firmware package, and there are 3 files in 
the folder. 
 
2. Copy these 3 files onto the USB drive in the following path 
“/4G-AC53U_LTE”. 
3. Insert the USB drive to the USB port of 4G_AC53U, and then open the 
administration webpage. Once the USB drive is being recognized, go to WAN 
> Internet Connection and select Mobile Broadband on "WAN Interface” item, 
you will see "New software version" shows up. 
 
4. Before performing the firmware update, please make sure the SIM card 
has been removed. After SIM card is removed, then click Update button to 
start LTE modem update process. 
5. Once the update is completed, the modem software version name will be 
changed accordingly.
